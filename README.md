# HPlay

เว็บแอป (PWA) รวมลิงก์เว็บไซต์ที่ใช้บ่อย เพิ่ม/แก้ไข/ลบ ค้นหา จัดหมวดหมู่ และใส่รายการโปรดได้ ข้อมูลเก็บในเครื่องผู้ใช้ (localStorage)

## Deploy ด้วย GitHub Pages
1. สร้าง repository ใหม่ แล้วอัปโหลดไฟล์ทั้งหมดไว้ที่ root (รวมโฟลเดอร์ `.github`)
2. Settings → Pages → Source: **GitHub Actions**
3. รอ workflow เสร็จ แล้วเปิด URL ที่ได้ → เมนูเบราว์เซอร์ → **ติดตั้งแอป / เพิ่มลงหน้าจอหลัก**

เมื่อแก้โค้ด ให้เปลี่ยนเลขเวอร์ชัน `CACHE` ใน `sw.js` เพื่อให้ผู้ใช้ได้เวอร์ชันใหม่
